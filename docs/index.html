Carnelian Playground

Carnelian is an mruby compiler backend written in pure Rust with support for Prism, lib-ruby-parser and soon its own Prism Rust port.

This playground uses the lib-ruby-parser frontend and the mrubyedge interpreter for a 100% Rust WASM executable with no clang nor Emscripten dependencies that compiles and runs ruby code locally in your browser (MRI grammar 3.1.2)
